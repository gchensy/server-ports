Server Ports — небольшое кроссплатформенное настольное приложение (Windows, macOS, Linux), которое поддерживает ваши SSH-переадресации портов. Выберите сервер, перечислите нужные порты — и они появятся на `localhost`. Это то же самое, что `ssh -L`, только без возни с терминалом.

## Возможности

- **Профили серверов**: один профиль на каждый SSH-сервер, с любым числом сопоставлений портов.
- **Три способа входа**: пароль, файл закрытого ключа (парольная фраза по желанию) или ssh-agent (агент OpenSSH или Pageant).
- **Секреты хранятся в системном хранилище учётных данных**: пароли и парольные фразы ключей лежат в «Связке ключей» macOS, «Диспетчере учётных данных» Windows или Secret Service в Linux, но не в файле настроек.
- **Проверка ключа хоста**: ключ ранее не виденного сервера показывается вместе с отпечатком и принимается только после вашего подтверждения; об изменившемся ключе предупреждают.
- **По умолчанию приватно**: переадресованные порты слушают только `127.0.0.1`, поэтому доступны лишь с вашего компьютера.
- **Автоматическое переподключение**: оборванные соединения восстанавливаются сами; профиль может также подключаться сразу при запуске приложения.
- **Состояние в реальном времени**: состояние соединения каждого сервера, состояние прослушивания каждого сопоставления, число открытых соединений и счётчики трафика.
- **Живёт в трее**: при закрытии окна приложение сворачивается в системный трей, а не завершается (это можно отключить).
- **Лёгкое**: построено на Tauri 2 — ядро на Rust и системный WebView, без встроенного браузера.

## Как это работает

Каждое сопоставление перенаправляет порт вашего компьютера на адрес, доступный SSH-серверу:

```text
127.0.0.1:8080 (ваш компьютер)  ──шифрованный SSH──►  127.0.0.1:80 (сервер)
```

Это равносильно `ssh -L 127.0.0.1:8080:127.0.0.1:80 user@server`. Целевой адрес разрешается на сервере, поэтому `127.0.0.1` означает сам сервер; подойдёт и любой другой хост, доступный серверу.

## Разработка

Требования:

- Node.js (актуальная LTS) и npm
- Rust 1.89 или новее ([rustup](https://rustup.rs))
- Системные зависимости Tauri для вашей ОС, см. [требования Tauri](https://tauri.app/start/prerequisites/). В Debian/Ubuntu:

```bash
sudo apt update
sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev
```

Затем:

```bash
npm install
npm run tauri dev    # запустить приложение с горячей перезагрузкой
npm run tauri build  # собрать установщики в src-tauri/target/release/bundle/
npm run typecheck    # проверить типы фронтенда
cargo test --manifest-path src-tauri/Cargo.toml  # запустить тесты Rust
```
